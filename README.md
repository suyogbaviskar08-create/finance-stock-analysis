# Stock Price Analysis & Forecasting (Finance Data Project)

End-to-end data science project on real market data: validation, exploratory analysis, a multi-stock risk/return comparison, feature engineering, next-day return and direction prediction against naive baselines, a back-test, and conclusions.

![Price chart](reports/figures/01_price_volume.png)

## Question
Can historical price and volume data help us (a) understand a stock's risk/return behaviour and (b) predict its next-day move well enough to be useful?

## Data
| File | Content | Source |
|---|---|---|
| `data/finance-charts-apple.csv` | Apple (AAPL) daily OHLCV, Feb 2015 to Feb 2017 (506 trading days) | [plotly/datasets](https://github.com/plotly/datasets) |
| `data/stocks.csv` | Monthly closing prices for MSFT, AMZN, IBM, GOOG, AAPL, 2000 to 2010 | [vega/vega-datasets](https://github.com/vega/vega-datasets) |

## Method
1. **Validation:** no missing values, duplicates or impossible prices.
2. **EDA:** trend and moving averages, volume, return distribution (fat tails), volatility clustering, Bollinger Bands, day-of-week test.
3. **Stock comparison:** growth of 100 invested, drawdowns, risk vs. return, correlations.
4. **Features:** returns over 1/2/5 days, distance from 5/20-day averages, 10-day volatility, RSI-14, volume ratio, intraday range and open-to-close move. All use data up to day *t*; targets are day *t+1* (no look-ahead).
5. **Models:** Ridge and Random Forest (regression); Logistic Regression and Random Forest (classification). Chronological 80/20 split, hyper-parameters tuned with `TimeSeriesSplit` on training data only.
6. **Baselines and back-test:** naive "no change" forecast, majority-class guess, and a long/cash strategy vs. buy-and-hold.

## Key results (test set: 98 trading days)
| Check | Result |
|---|---|
| Return RMSE: naive vs. Ridge vs. Random Forest | 1.075% vs. 1.080% vs. 1.080%: models do **not** beat the naive forecast |
| Direction accuracy: Random Forest / Logistic | 52.0% / 49.0% (always guessing "up" would give 57.1%) |
| Back-test total return: model vs. buy-and-hold | 6.8% vs. 19.7% (no trading costs) |
| Volatility | Clusters: absolute returns are autocorrelated even though returns are not |

**Conclusion:** consistent with weak-form market efficiency, simple price/volume features carry almost no exploitable directional signal for a heavily traded large-cap stock. Risk (volatility) is more predictable than direction. Full discussion, limitations and next steps are in the notebook.

## Project structure
```
finance-stock-analysis/
├── data/                         # bundled CSV datasets
├── notebooks/
│   └── Finance_Stock_Analysis_Project.ipynb   # full narrative analysis with outputs
├── src/
│   ├── data_loader.py            # load datasets (local first, URL fallback)
│   ├── features.py               # feature engineering (no leakage)
│   └── models.py                 # split, models, metrics, back-test performance
├── tests/test_pipeline.py        # data-quality, leakage and split tests
├── reports/
│   ├── figures/                  # charts generated by run_analysis.py
│   └── metrics.json              # results summary
├── run_analysis.py               # one command to run everything
├── requirements.txt
└── .github/workflows/ci.yml      # runs tests + analysis on every push
```

## Run it locally
```bash
git clone https://github.com/<your-username>/finance-stock-analysis.git
cd finance-stock-analysis
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python run_analysis.py           # regenerates reports/figures and reports/metrics.json
pytest -q                        # optional: run the tests
jupyter notebook notebooks/Finance_Stock_Analysis_Project.ipynb
```

## Limitations
About 500 daily observations and a 98-day test window give noisy estimates; one stock in one market regime; price-based features only; the back-test ignores costs and slippage. Educational project, not investment advice.
